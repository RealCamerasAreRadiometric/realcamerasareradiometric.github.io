Set up the data and the hardware

The package installs as the Installation says, with every dependency from the General registry. This page is for what the package does not install: the hardware a calibration runs on, and the data of the experiments.

Clone

The repository holds the package (RadiometricCamera/), the experiments that reproduce the paper (experiments/), the manuscript and the project page, and no data:

git clone https://github.com/RealCamerasAreRadiometric/realcamerasareradiometric.github.io.git
cd realcamerasareradiometric.github.io
julia +1.13 --project=RadiometricCamera -e 'using Pkg; Pkg.instantiate()'

The package tests need no data: their fixtures are committed under test/fixtures/.

Data

The experiments' inputs — the raw photographs, the synthetic renders, the baseline calibrations of the external front ends (Schöps et al.'s pipeline, Kalibr, OpenCV, BlobBoards), the targets and the calibration cases — are the paper project's published data, tiers of lazy Julia artifacts catalogued in experiments/configs/data_artifacts.toml. experiments/REPRODUCE.md says how to fetch them (experiments/scripts/fetch_data.jl) and how to bind a copy of one's own (VGTK_DATA_ROOT); the package's checks name the tier they read (rc_calibration).
